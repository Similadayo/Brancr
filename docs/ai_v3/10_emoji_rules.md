# EMOJI SAFETY RULES (SINGLE SOURCE OF TRUTH)

1. **Emojis never appear in payment instructions.**
   - Account numbers, amounts, and sort codes must be plain text.
   - Clarity > cute.

2. **Emojis never appear in error messages.**
   - If something fails, be serious and clear.
   - "Payment failed 😢" is unprofessional. Use "Payment failed. Please try again."

3. **Emojis only appear in informal platforms.**
   - WhatsApp/Instagram: OK (limit density).
   - SMS/Web (Formal): NO (unless brand voice dictates).

4. **Max 2 emojis per message.**
   - Do not spam icons.
   - Use them as punctuation, not content.
