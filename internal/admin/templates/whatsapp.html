Manage phone numbers in Brancr's provider-owned WABA

📋 How to Add Phone Numbers

For Admin-Provided Numbers:
  1. Add the phone number in Meta Business Manager
  2. Meta will send a verification code to the phone number
  3. Enter the verification code in Meta's UI to complete verification
  4. Click "🔄 Sync from Meta" below to import the number into Brancr's database
  5. The number will appear in the table with status "Available"
For Tenant-Provided Numbers:
  1. Tenant requests their phone number to be added (via support/dashboard)
  2. Admin adds the tenant's phone number in Meta Business Manager
  3. Meta will send a verification code to the tenant's phone number
  4. Tenant provides the verification code to admin, or admin enters it in Meta's UI
  5. Click "🔄 Sync from Meta" below to import the number into Brancr's database
  6. The number will appear in the table with status "Available"
  7. Tenant can then request a verification code (via dashboard) to claim ownership, or admin assigns it directly
💡 Note: All phone numbers must be added manually in Meta Business Manager first. Brancr's "Sync from Meta" button only imports numbers that already exist in your WABA. Meta's API does not support programmatically adding phone numbers.
